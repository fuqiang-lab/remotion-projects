# 视频风格库 · Dark Desk（暗色讲台风）

> 风格出处：`References/动画效果.mp4`（1280×720 / 30fps，293.8 s）。抽帧逐像素取色得到底色、卡片灰、橘色强调、白色手绘斜线与深色口播胶囊。
> 为课堂投影做了**提亮**：底色比参考片（`#131116`）亮一档，正文对比度 ≥ 7:1。
> 本目录是该风格的可复用实现；`effects/prompt-design/` 是按此风格做的成片示例（《AI 提示词设计方法与优化策略》精讲，20 屏）。

---

## 1. 这套风格是什么

**一句话**：像在暗下来的教室里，一位讲师在白板前边讲边划重点——底子是暗的，字是亮的，重点用粉笔圈出来。

| 维度 | 做法 |
| --- | --- |
| 气质 | 讲座 / 研修感，理性、不炫技；暗场不靠霓虹特效，靠对比与留白 |
| 底色 | 近黑偏中性（`#17161A`），四周极淡的暗角，不放网格与噪点 |
| 文字 | 思源黑体（Noto Sans SC）900 做主标题，关键词染橘；正文 400/500 |
| 图形 | 深灰卡片（`#222127`）+ 1px 描边；只有需要时用米白"纸"色 |
| 强调 | 橘 `#E2724A` 一处关键词 + 白粉笔线/圈；蓝/绿/黄只作语义（对比、通过、警示） |
| 口播 | 底部居中的深色胶囊（`#0E0D10`），全片常在 |
| 导航 | 顶部细线 + 左品牌 + 右「章节号 · 名称」，章节随进度点亮 |
| 节奏 | 每屏只讲一件事，内容依次「上浮 + 淡入」，重点用粉笔线在讲到的时刻划出 |

全部在 `theme.ts` 的 `C` / `F` / `L` 里，**场景里不要另写色值**。

## 3. 组件（`ui.tsx`）

| 组件 | 作用 |
| --- | --- |
| `Desk` | 全片底板（底色 + 暗角 + 顶部/底部落影）。**只在父级用一次**，场景不要自己铺背景 |
| `Nav` | 顶栏：左品牌 + 右「章节号 · 名称」 |
| `Stage` | `Nav` + 眉标 + 主标题的组合，场景开头一行搞定 |
| `SceneFrame` | 场景外壳：统一 14 帧首尾淡化、留出字幕带 |
| `SceneTitle` | 只要标题（用于没有导航的场景） |
| `CaptionPill` | 底部口播胶囊，`start` 传口播起始帧 |
| `Card` | 深灰卡片（`padding` / 描边色可覆盖） |
| `Tag` | 小标签（圆角 6，`tone` 取 semantic 色） |
| `ChalkLine` | 白色手绘直线/斜线，按帧"画"出来 |
| `ChalkCircle` | 白色手绘圈，圈住关键词 |
| `Num` | 等宽序号（`01` / `02`） |
| `Arrow` | 细箭头 |
| `Mark` | 勾 / 错 / 警示徽标 |
| `pop` / `jitter` | 弹出动画、确定性微抖（不依赖 `Math.random`） |

### 动效原语（`theme.ts`）

| 函数 | 用法 |
| --- | --- |
| `rise(frame, start, distance=18, duration=16)` | 上浮 + 淡入，返回可直接铺开的 style |
| `pop(frame, fps, start)` | 弹簧缩放入场 |
| `progress(frame, start, end)` | 0→1 进度（画线、进度条） |
| `sceneFade(frame, total)` | 场景首尾淡化 |
| `stagger(base, i, gap=8)` | 错峰 |
| `clamp(v, min=0, max=1)` | **数值截断**（不是给 interpolate 的选项） |
| `clampOpt` | 给 `interpolate` 的 `extrapolate` 选项用 |

> 踩过的坑：把 `clamp` 当成 `{extrapolateLeft:'clamp'}` 常量写，再当函数调用会直接 TS 报错；两者已拆成 `clamp` / `clampOpt`。

## 4. 写一屏的标准流程

1. 场景组件签名固定为 `React.FC<SceneProps>`，`line` 来自 `narration.ts`（`{ name, text, vo }`）。
2. 开头 `const voStart = Math.round(0.6 * fps)`，之后所有出现时刻都写成 `voStart + Math.round(秒 * fps)`，**按口播节奏排，不按帧数猜**。
3. 第一节用 `<Desk><Stage chapter={n} chapters={CHAPTERS} label=".." title=".." accent=".." /></Desk>`。
4. 主体按「先定位、后内容」写：`position:absolute` + 明确的 `left/top/width`，不靠 flex 撑高。
5. 重点在讲到的时刻用 `ChalkLine` / `ChalkCircle` 划出来。
6. 最后 `<CaptionPill text={line.text} start={voStart} />`。
7. 改完渲一张**中段帧**静帧看排版（`npx remotion still <CompId> out.png --frame=N`）。

---

## 5. 场景时长规则（与配音对齐）

```
场景帧数 = 口播秒数 × fps + 0.6 s 入 + 0.85 s 出
Sequence 之间重叠 0.4 s（12 帧），避免切换时闪空底板
```

配音数组 `NARRATION[].vo` 由实测音频时长回填，**先配音、后定画面**。
