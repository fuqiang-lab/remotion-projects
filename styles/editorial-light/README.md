# 视频风格库 · Editorial Light（米白编辑风）

> 风格出处：`References/remotion视频创作教程.mp4`（1280×720 / 30fps，红白胶囊式口播字幕）。
> 本目录是该风格的可复用实现；`effects/dsh-intro/` 是按此风格做的成片示例。

---

## 1. 这套风格是什么

**一句话**：像一本印刷精致的产品说明册，用动画把它翻成 2 分钟的视频。

特征组合：

| 维度 | 做法 |
| --- | --- |
| 气质 | 干净、克制、教学感；不炫技、不出镜头运动特写 |
| 底色 | 冷调米白（不是纯白），顶部隐现浅灰网格 |
| 文字 | 深墨色中文黑体做主标题，关键词染橙/蓝 |
| 图形 | 白色圆角卡片 + 淡蓝等轴测地台 + 细描边图标 |
| 口播 | 底部居中的深灰胶囊字幕，几乎全片常在 |
| 导航 | 顶部细线 + 左品牌 + 右「章节号 · 名称」 |
| 节奏 | 每屏只讲一件事，内容依次「上浮+淡入」 |

## 2. 设计令牌（Design Tokens）

实测自参考视频，可用 `theme.ts` 直接引用。

### 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `paper` | `#F4F3F8` | 全片底色（冷调米白） |
| `paper2` | `#EDEBF2` | 次级背景 / 分隔 |
| `ink` | `#22252D` | 主标题、正文强调 |
| `ink2` | `#3A3F4B` | 正文 |
| `muted` | `#8C8FA0` | 说明文字、眉标以外的次要信息 |
| `line` | `#E2E0E7` | 描边、分隔线、网格 |
| `accent` | `#E06C3C` | **主强调色**：关键词、序号、正向按钮 |
| `accentSoft` | `#FBE7DC` | 强调色底（标签底、选中卡片） |
| `blue` | `#4C74E0` | 次强调：对比项、图表 |
| `blueSoft` | `#E4ECFB` | 蓝底标签 |
| `green` | `#2E9E6A` | 完成态、勾选 |
| `purple` | `#7A5BD6` | 第三类语义（可选） |
| `card` | `#FFFFFF` | 卡片 |
| `pill` | `#343C4A` | 口播胶囊字幕（实测值） |
| `plane` | `#CFE3F8` | 等轴测地台台面 |

> **强调色只用一处**：一屏里橙色最多出现在「一个关键词 + 一个图标 + 一个序号」，多了就变成电商风。

### 字号（1280×720 基准，按宽度等比缩放）

| 角色 | 字号 | 字重 | 说明 |
| --- | --- | --- | --- |
| 主标题 | 44–48 | 900 | 一行为主，最长不超过 ~20 个汉字 |
| 关键词强调 | 同主标题 | 900 | 染 `accent` |
| 眉标（eyebrow） | 13 | 800 | 全大写 + 字距 4 + `accent` |
| 卡片标题 | 20–27 | 900 | |
| 正文 | 14–16 | 400–600 | 行高 1.5 |
| 口播字幕 | 24 | 600 | 白字深底 |
| 代码 / 编号 | 12–14 | 400–500 | 等宽字体 |

字体：中文 `Noto Sans SC`，西文数字 `Inter`，代码 `JetBrains Mono`（均来自 `@remotion/google-fonts`）。

### 间距与圆角

- 左右安全边距 **64px**（≥ 宽度的 5%）；顶部导航 28px；底部字幕带预留 **124px**。
- 卡片圆角 **16px**，标签圆角 6–8px，胶囊 999px。
- 卡片阴影：`0 2px 4px rgba(20,24,31,.03), 0 14px 34px rgba(20,24,31,.07)`（两层，近实远虚）。
- 卡间距 12–20px；页面主体区大致 `y = 190 → y = 490`。

### 动效

| 行为 | 参数 |
| --- | --- |
| 入场 | 上浮 16–24px + 淡入，`Easing.bezier(0.16,1,0.3,1)`，16–20 帧 |
| 卡片弹出 | `spring({damping:15–17, mass:0.6–0.7})`，缩放 0.86 → 1 |
| 内容错峰 | 相邻元素间隔 7–12 帧 |
| 场景切换 | 场景自身首尾淡入淡出 14 帧，场景之间留 0.4s 重叠 |
| 高亮游走 | 环形高亮每 6–8 帧切换，循环 |

## 3. 版式骨架

```
┌──────────────────────────────────────────────────────────┐
│ DSH  DEEPSEEK HARNESS │ 认识 DSH        03 章节名      ⊙ │ ← Nav（顶部 28px，细线收尾）
│                                                          │
│  LOOP · 眉标                                             │ ← SceneTitle（left 64, top 96）
│  较大的主标题，关键词染橙色                                 │
│                                                          │
│   ┌────────┐  ┌────────┐  ┌────────┐                     │ ← 主体：卡片网格 / 地台 / 流程图
│   │ 卡片   │  │ 卡片   │  │ 卡片   │                     │   （top ≈ 200）
│   └────────┘  └────────┘  └────────┘                     │
│                                                          │
│              ┌──────────────────────┐                    │ ← CaptionPill（底部居中，bottom 26）
│              │  这一屏的口播那一句    │                    │
│              └──────────────────────┘                    │
└──────────────────────────────────────────────────────────┘
```

**画面类型**（参考视频里反复出现的 6 种）：

1. **居中标题页** — 大字标题 + 一行小字 + 胶囊，用于开场/收尾。
2. **卡片网格页** — 3–5 张白卡等宽排开，每张一个图标 + 标题 + 一句说明。
3. **左文右图页** — 左侧步骤/列表，右侧等轴测地台或示例图。
4. **对比页** — 两张卡左右并列（允许/禁止、前/后）。
5. **流程页** — 横向 5 节点 + 箭头，可带回环。
6. **列表 + 详情页** — 左列分类，右列具体条目逐条出现。

## 4. 怎么用（30 秒上手）

```tsx
import { Nav, Paper, SceneTitle, CaptionPill, Card, Tag, SceneFrame, rise, C, F } from "../../styles/editorial-light";
import { useCurrentFrame } from "remotion";

export const MyScene: React.FC = () => {
  const frame = useCurrentFrame();
  return (
    <SceneFrame padBottom={124}>
      <Nav chapter={1} label="我的章节" />
      <SceneTitle label="FEATURE · 特点" title="这一屏只讲一件事" accent="只讲一件事" />
      <Card style={{ position: "absolute", left: 64, top: 220, width: 400, padding: 20, ...rise(frame, 12) }}>
        <Tag color={C.accent} bg={C.accentSoft}>label</Tag>
        <div style={{ fontFamily: F.sans, fontSize: 22, fontWeight: 900, color: C.ink }}>卡片标题</div>
      </Card>
      <CaptionPill text="口播这一句" start={24} />
    </SceneFrame>
  );
};
```

然后在 `src/Root.tsx` 注册 Composition（1280×720 / 30fps），多场景用 `Sequence` 拼：

```tsx
<Sequence from={0} durationInFrames={7 * 30}><SceneA /></Sequence>
<Sequence from={7 * 30} durationInFrames={9 * 30}><SceneB /></Sequence>
```

## 5. 制作检查清单

- [ ] 每屏只讲**一个**结论，标题就是那个结论（不要写「功能介绍」这种名词标题）。
- [ ] 主标题 ≤ 20 汉字，关键词染色 ≤ 6 字。
- [ ] 一屏橙色不超过 3 处。
- [ ] 所有关键文字离边 ≥ 64px；底部内容不进入 124px 字幕带。
- [ ] 每个元素都从 `useCurrentFrame()` 推导；禁止 `Date.now()` / `Math.random()`。
- [ ] 场景之间加 0.4s 重叠淡化，不要硬切、也不要露白。
- [ ] 有配音时：**场景时长 = 口播时长 + 0.6s 入 + 0.85s 出**。
- [ ] 导出前 `npm run lint` 通过。

## 6. 配音规范（配合本风格）

参考视频是「画面 + 口播 + 字幕胶囊」三位一体，本风格默认也这么做：

- 每屏一句，口语化、结论先行（例：「它不是聊天框，而是一个能在终端里干活的同事」）。
- 语速 ~5.5 字/秒；单句 ≤ 40 字。
- 字幕胶囊**逐屏**显示该句，不是逐字流式字幕。
- 音量统一到 **−16 LUFS**、峰值 ≤ −1.5 dB（多句合成时句间容易差 6dB，务必归一）。

本机可用 Qwen3-TTS 做声音克隆，命令见 `README-AUDIO.md`。
