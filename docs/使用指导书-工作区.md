## 一、先记住四件事

| 你要做的事 | 放哪里 | 要不要告诉 Agent |
| --- | --- | --- |
| 放**原始材料**（PPT、Word、PDF、截图） | `input\` | 要，说一句"材料在 input 里" |
| 放**参考视频**（想模仿风格的片子） | `References\` | 要，说一句"参考视频在 References 里" |
| 找**做好的视频** | `out\` | 不用，Agent 会告诉你路径 |
| 改**颜色/版式/风格** | `styles\` | 不用，说"换成 XX 风格"即可 |

**一句话原则**：`input\` 和 `References\` 是你的入口，`out\` 是你的出口，中间过程都归 Agent 管。

## 二、目录职责（完整版）

```
Remotion-Projects\
├─ input\                    ← 你放材料：PPT / Word / PDF / 图片
├─ References\               ← 你放参考视频（学风格用，不参与渲染）
├─ out\                      ← 成片都在这里
├─ effects\                  ← 每个作品一个目录（Agent 写代码的地方）
│   ├─ smoke-test\           ← 部署自检用，别删
│   ├─ dsh-intro\
│   ├─ skill-mechanism\
│   └─ prompt-design\
├─ styles\                   ← 风格库（两套：米白编辑风 / 暗色讲台风）
├─ public\                   ← 渲染时要读的素材（配音、图片），Agent 维护
├─ docs\                     ← 文档
└─ src\                      ← 脚手架，一般不用碰
```

### 各目录说明

| 目录 | 放什么 | 举例 |
| --- | --- | --- |
| `input\` | **你的原始材料**，怎么放都行 | `AI赋能教学设计专题研修-提示词设计.pptx` |
| `References\` | **参考视频**，用来定风格 | `remotion视频创作教程.mp4`、`动画效果.mp4` |
| `out\` | **成品**，按作品名建子目录 | `out\smoke\smoke-test.mp4` |
| `effects\<作品名>\` | 一个作品的全部代码与素材 | `effects\prompt-design\` |
| `styles\<风格名>\` | 一套颜色、字号、组件 | `styles\editorial-light\` |
| `public\<作品名>\vo\` | 该作品的配音 mp3 | `public\prompt-design\vo\00.mp3` |

> [!tip] `References\` 和 `public\` 别搞混
> `References\` 里的视频**只给人看**，Agent 会从里面抽帧取色、学版式；
> 真要把某个视频/图片**放进画面**，才需要它进 `public\`（这一步 Agent 会做）。

## 三、怎么打开、怎么看效果

### 打开预览（最常用）

在工程目录打开终端，执行：

```powershell
npm run dev
```

然后浏览器打开 `http://localhost:3000`（终端会打印实际地址）。
左侧是作品列表，点任意一个就能播放、拖时间轴、逐帧看。

- 想直接看某个作品：`http://localhost:3000/SmokeTest`
- 关掉预览：在终端按 `Ctrl+C`
- 端口被占用：`npx remotion studio --port 3001`

### 导出成片

在预览界面里点右上角的渲染按钮最省事；
或者直接说"导出成 MP4"，Agent 会执行渲染并告诉你 `out\` 下的路径。

### 部署自检（怀疑环境坏了时）

```powershell
npx remotion render SmokeTest out\smoke\smoke-test.mp4
```

这条能成功 = 环境没问题，问题在具体作品上。

## 四、素材怎么放（重要）

### 放材料的正确姿势

1. 直接把文件丢进 `input\`，**不用改名**、不用转格式
2. 告诉 Agent：**"材料在 input 里，文件名是 XXX"**
3. 想指定结构：可以在提示词里说"按第 1、3、5 页做，跳过第 2 页"

### 放参考视频的正确姿势

1. 丢进 `References\`
2. 告诉 Agent：**"参考 References\xxx.mp4 的风格"**
3. 如果只想学某一小段，说"参考第 30 秒到 1 分钟那段"

> [!warning] 路径不要带中文和空格
> 工程路径本身必须是纯英文。文件放在 `input\` 里可以是中文名，但**工程目录**不能。

### 命名建议

| 类型 | 建议命名 | 理由 |
| --- | --- | --- |
| 材料 | `主题-来源.pptx` | 便于区分多份材料 |
| 参考视频 | `风格描述.mp4` | 如 `暗色讲台.mp4`、`米白编辑风.mp4` |
| 作品目录 | `英文小写-用途` | 如 `prompt-design`、`skill-mechanism` |
| 成片 | 中文标题 | 如 `out\AI提示词设计-精讲.mp4` |

## 五、示例提示词（可直接照抄）

### 1. 从材料做一个新视频

> 材料在 `input\AI赋能教学设计专题研修-提示词设计.pptx`，
> 帮我做一个 3 分钟左右的讲解视频，10–15 屏，每屏一句话，1280×720。
> 先只做预览，我要在 Studio 里看效果。

### 2. 复刻参考视频的风格

> 参考 `References\动画效果.mp4` 的视觉风格：暗色背景、橘色强调、粉笔线手绘感。
> 先抽帧取色，把实测色值写进 `styles\dark-desk\README.md`，再按这个风格做一屏样张给我确认。

### 3. 给现有作品加配音

> 给 `effects\prompt-design` 配上我的声音，用本机 Qwen3-TTS 克隆。
> 参考音频用 `References\付强声音新录制.m4a`。每屏一句，做完先让我试听一屏。

### 4. 改版式（不重做内容）

> 现在这屏标题太大、卡片挤在一起。帮我把字号调小、卡片间距加大，
> 改完渲几帧静帧给我看，不要整片重渲。

### 5. 导出成片

> 把 `PromptDesign` 导出成 MP4，放在 `out\AI提示词设计-精讲.mp4`，导出后告诉我时长和分辨率。

### 6. 只改一句话

> 第 7 屏的口播改成"提示词不是越长越好"，画面文字同步改，其他不要动。

## 六、两套现成风格

| 风格 | 目录 | 长什么样 | 适合 |
| --- | --- | --- | --- |
| Editorial Light（米白编辑风） | `styles\editorial-light\` | 米白底 + 白卡 + 淡蓝地台 + 深灰口播胶囊 | 教学、正式讲解 |
| Dark Desk（暗色讲台风） | `styles\dark-desk\` | 暗底 + 深灰卡 + 橘色强调 + 粉笔线 | 技术分享、有冲击力的内容 |

想换风格就直接说："把这部片子换成暗色讲台风"。Agent 会替换 `theme.ts` / `ui.tsx` 的引用，不会逐屏改颜色。

## 七、常见问题

| 现象 | 原因 | 你自己能做的 |
| --- | --- | --- |
| 预览打不开 | `npm run dev` 没在跑 | 重新执行，看终端有没有报错 |
| 端口 3000 被占 | 上次没退干净 | 关掉旧终端窗口，或让 Agent 换端口 |
| 渲染报 Permission denied | 系统临时目录不可写 | 交给 Agent（需设一个环境变量） |
| 导出的视频没有声音 | 该作品本来没配音 | 说"帮我加配音" |
| 文字溢出画面 | 版式没算好 | 说"第 N 屏文字超出去了，渲静帧排查" |
| 中文变成方框 | 缺字体或用了 emoji | 让 Agent 换成 SVG/字体方案 |

> [!note] 什么时候该叫 Agent
> 你只需要判断"**内容对不对**"和"**好不好看**"；
> 路径、依赖、渲染参数、字体这些技术问题，直接描述现象即可，不用自己排查。
